# 多语言本地化

Unity 图片多语言本地化工具。

## 安装

在 Unity Package Manager 中通过 git URL 安装：

```
https://github.com/KevienHou/Packtools.git?path=/Packages/com.packtools.tools.localization
```

## 使用

安装后通过 Unity 菜单 `Tools > Language Localization` 访问功能。

详细教程见 `Runtime/LanguagLocalization/README_使用教程.md`。

## 版本更新

改版本号后打 git tag，用户在 Package Manager 中点 Update 即可获取最新版本。
